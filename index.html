Cara angka dihitung dan dikoreksi

Skor arah. S = 0.25·tanh((EMA20−EMA50)/ATR) + 0.20·tanh((C−EMA20)/ATR) + 0.20·R + 0.20·tanh(Hist/(0.25·ATR)) + 0.15·Struktur. R = (RSI14−50)/50 dengan koreksi mean-reversion di atas 75 dan di bawah 25. Struktur = +1 (HH/HL), −1 (LH/LL), 0 (campuran) dari pivot fractal 2 bar.

Top-down. D1 memakai skornya sendiri; H1 = 0.7·S + 0.3·SD1; M30, M15, M5 = 0.55·S + 0.45·rata-rata(SD1, SH1). Hanya candle TF besar yang sudah tutup yang dipakai, supaya backtest tidak mengintip masa depan.

Probabilitas awal. P↑ = 0.6·σ(2.2·S) + 0.4·(2+k)/(4+m), dengan m candle sebelumnya yang skornya mirip (|ΔS| < 0.2) dan k di antaranya diikuti candle naik (prior Beta(2,2)). P↔ = clamp(0.12 + 0.55·(1−ER)·(1−|tanh 2S|), 0.10, 0.60), ER = efficiency ratio 14 bar. Bullish = (1−P↔)·P↑, Bearish = (1−P↔)·(1−P↑).

Backtest. Untuk setiap candle historis i (mulai candle ke-60), model memprediksi candle i+1 hanya dari data sampai i. Hasil nyata diberi label naik jika ΔC > 0.15·ATR, turun jika ΔC < −0.15·ATR, selain itu sideways.

Koreksi. Probabilitas dikalibrasi ulang dengan regresi logistik multinomial: P′k ∝ exp(a·ln Pk + bk). Parameter a, b dicari dengan gradient descent pada 70% data backtest pertama, lalu diuji pada 30% terakhir. Koreksi hanya dipakai jika skor Brier di data uji membaik; jika dipakai, parameter dihitung ulang dari seluruh backtest. a mendekati 0 berarti sinyal model lemah dan prediksi ditarik ke base rate.

Target. Sebelum backtest: High = C + ATR·(0.5 + 0.35·k), Low = C − ATR·(0.5 − 0.35·k), k = Bullish − Bearish. Setelah backtest, koefisiennya diganti hasil regresi linear jarak High dan Low candle berikutnya (dalam satuan ATR) terhadap k.

Data live. Twelve Data: M5 (5.000 candle), H1, dan D1 diambil langsung; M15 dan M30 dibangun dari M5. Binance: kelima TF diambil langsung (1.000 candle). Candle yang masih berjalan dibuang dan harga terakhirnya dipakai sebagai harga acuan. Backtest dan koreksi diulang penuh pada setiap pembaruan, jadi candle yang baru tutup langsung ikut dihitung.

Asumsi. Pada mode manual, baris terakhir tiap TF dianggap candle yang sudah tutup. Maksimal 1.500 candle terakhir per TF yang dipakai.
